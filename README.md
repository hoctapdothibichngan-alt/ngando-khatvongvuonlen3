# KHÁT VỌNG VƯƠN LÊN

## Mở website
Giải nén toàn bộ ZIP, giữ `index.html`, `avatar.png`, `hanh-trinh-tri-thuc.png` và thư mục `fonts` cùng nhau, rồi nhấp đúp `index.html`. Website hoạt động trên điện thoại và máy tính; công cụ mục tiêu, kế hoạch, sổ ghi chép lưu trên trình duyệt đang dùng. Xuất bản sao lưu JSON trước khi xóa dữ liệu trình duyệt hoặc chuyển thiết bị. Không nhập dữ liệu nhạy cảm trên máy dùng chung.

## Đưa lên GitHub Pages
1. Đăng nhập GitHub, tạo repository mới, đặt tên ví dụ `khat-vong-vuon-len`, chọn Public.
2. Trong repository, chọn Add file → Upload files. Tải các file `index.html`, `avatar.png`, `hanh-trinh-tri-thuc.png` và thư mục `fonts` lên thư mục gốc, rồi chọn Commit changes.
3. Chọn Settings → Pages. Trong Build and deployment, chọn Deploy from a branch; chọn branch `main`, thư mục `/ (root)`, nhấn Save.
4. Đợi GitHub công bố địa chỉ trong Settings → Pages; mở đường dẫn đó để kiểm tra. Nếu chưa xuất hiện, đợi thêm vài phút và tải lại trang.
5. Để cập nhật, sửa file rồi tải phiên bản mới lên repository và commit. GitHub sẽ triển khai lại.

## Phạm vi
Website tĩnh không có máy chủ, tài khoản, cơ sở dữ liệu, đồng bộ, gửi thư hay lưu bút công khai. Những tính năng này cần tích hợp dịch vụ ngoài, chính sách dữ liệu và kiểm thử riêng. Không đưa mật khẩu hay khóa bí mật vào mã công khai. Thay ảnh bằng file `avatar.png` khác, hoặc sửa đường dẫn trong CSS. Nội dung chỉnh trực tiếp trong `index.html`.
